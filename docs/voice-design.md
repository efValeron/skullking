# Голосовой ввод: требования и дизайн

## Требования (со слов пользователя)
- Ввод имён игроков по очереди.
- Ставки в формате «имя количество». Если имя пропущено, у игрока 0.
- В конце раунда: кто сколько взял, бонусы и Кракен.
- Главное: отсеивать шум. За столом кто-то просто говорит имена, и это не должно считаться командой.

Допущение: команды диктует один человек (ведущий счёт), остальные разговаривают рядом.

## Принципы отсева шума (в порядке важности)
1. **Голос пишет только в черновик.** В игру результат попадает после тапа «Принять» (или голосом «принять» по той же кнопке «Говорить»). Есть «Отмена» последнего принятого. Даже если шум пролез, очками он не станет.
2. **Микрофон включается только кнопкой «Говорить»** (зажать или тапнуть, закрывается по паузе около 1,5 с) и только в трёх окнах: имена, ставки, итоги раунда. Во время игры он выключен. Слово-активатор не использовать: «кракен», «русалка», «пират» игроки выкрикивают сами.
3. **Строгая грамматика.** Каждое слово фразы должно быть понято: имя из списка игроков (с падежами), число в допустимом диапазоне, команда окна или короткое служебное слово. Одно лишнее слово, и вся фраза отклоняется.
4. **Имя без числа не команда.** Ноль только явный («Аня ноль»). Неупомянутые игроки получают 0 при завершении черновика ставок.
5. **Проверки по смыслу.** Ставка от 0 до числа карт. Сумма взяток равна числу карт (на 1 меньше, если был Кракен), иначе «Принять» заблокирована. Бонус засчитывается только при сошедшейся ставке (как и в оригинале).
6. **Несколько вариантов распознавания.** Движок отдаёт список вариантов (в Web Speech API это `maxAlternatives`), берётся первый, который проходит грамматику. Это заметно повышает точность имён.

## Окна и фразы
**Имена** (поле игрока №N подсвечено): одна фраза равна одному имени. По умолчанию одно слово, дефис допустим (`maxWords` настраивается). Не число, не команда, не дубль. «Готово» завершает ввод имён. Если имя похоже на уже введённое (Аня / Ваня), показать предупреждение и предложить прозвище.

**Ставки:** «Аня два, Дима один, Оля три», «ставки: у Ани два». Остальные получают 0.

**Итоги раунда:**
- взятки: «Аня два, Дима один, Оля ноль»;
- Кракен: «кракен», «без кракена»;
- бонусы: «Аня бонус сорок», «Дима бонус четырнадцать» (+10), «Дима бонус чёрная четырнадцать» (+20), «Оля русалка побила чёрного пирата» (+40), «Иван пират побил русалку» (+20), «Иван чёрный пират побил пирата» (+30), «Аня лут» (+20).
- итоги можно диктовать частями, черновик накапливается (`mergeResults`).

## Отображение черновика
Фишки на экране: «Аня 2 · Дима 1 · Оля 0 (по умолчанию)». Распознанное имя и число видно сразу, правка тапом по фишке (те же степперы, что в обычном UI). Если фраза отклонена: показать «Не понял: …» и слово, на котором остановился разбор, ничего не менять.

## Движок речи
- Web (PWA): Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`), `lang = 'ru-RU'`, `interimResults = true`, `maxAlternatives = 5`. Лучше всего в Chrome на Android; в Safari/iOS (особенно в установленной PWA) бывают проблемы с микрофоном, в Firefox API нет. Обычно нужен интернет. Грамматики (`SpeechGrammarList`) в Chrome фактически игнорируются, поэтому отсев делается после распознавания.
- Нужны офлайн или жёсткий отсев на уровне движка: Vosk (малая русская модель около 50 МБ) с ограниченным словарём (имена игроков, числа, служебные слова; всё остальное превращается в `[unk]` и отклоняется).
- Движок должен быть за интерфейсом (`start()`, `stop()`, `onResult(alternatives: string[])`), чтобы заменять его без правки логики.

## Ядро `voice-core/`
Чистый TypeScript без зависимостей (`parser.ts`), 71 тест (`npm install && npm test`), общий набор случаев в `cases.json` (его можно прогнать и на другом языке).
- `parseName(alts, players, { maxWords? })`
- `parseBids(alts, players, { cards })` → черновик `{ bids }`; `mergeBids`, `completeBids` (нули для неупомянутых)
- `parseResults(alts, players, { cards })` → черновик `{ tricks, bonus, kraken? }`; `mergeResults`
- `validateResults({ players, cards, draft, kraken?, bids? })` → `Issue[]` (`sum_mismatch` блокирует «Принять», `bonus_ignored` предупреждает)
- Результат парсера: `{ ok: true, draft, warnings, heard }` или `{ ok: false, reason, detail?, heard }`.

Допущения ядра (менять в `parser.ts`): «четырнадцать» считается бонусом только после слова «бонус»; события вроде «русалка побила чёрного пирата» работают без слова «бонус»; числа для бонуса кратны 10.

## Проверка шумом
Прогон 17 фраз с болтовнёй за столом («Дима, у тебя два туза», «Андрей, кракен выйдет, зуб даю», «Аня, ходи уже» и т. п.): 14 отклонены, пропущены только 3 фразы, которые буквально выглядят как команда («Аня два», «Оля один», «Иван, один»). Их отличить нельзя никакой грамматикой, поэтому обязательны черновик и подтверждение. При доработке грамматики добавляй новые шумовые фразы в `cases.json`.

## Решения (этап 4, 2026-11-05)
Валерий не ответил на открытые вопросы, взяты рекомендации; поменять можно, логика от них не зависит:
1. Кнопка «Говорить»: тап, одна фраза, браузер сам останавливает после паузы. Повторный тап во время записи — стоп.
2. Голосового ответа нет.
3. Без офлайна: Web Speech API. Vosk можно подключить за тем же интерфейсом `SpeechEngine`.
4. Целевое устройство — Android Chrome. На iPhone (Safari, особенно установленная PWA) Web Speech API ненадёжен; если играете на iPhone, вопрос движка нужно открыть заново.
5. Голос работает только в русской локали (грамматика voice-core русская). В en и в браузерах без Speech API блок «Говорить» скрыт.

## Реализация
- `src/voice/engine.ts` — интерфейс `SpeechEngine` и адаптер Web Speech API (`ru-RU`, `interimResults`, `maxAlternatives = 5`).
- `src/voice/drafts.ts` — перевод черновиков voice-core в действия игры, тексты отказов, команды «принять» / «отмена»; тесты рядом.
- `src/voice/Voice.tsx` — хук `useSpeech` и блок `VoiceBox`: кнопка, промежуточный текст, фишки черновика, «Принять» / «Отмена», «Вернуть как было».
- Окна:
  - имена — `Players.tsx`: форма сама служит черновиком, имя попадает в подсвеченное пустое поле;
  - ставки — `Bids.tsx`: «Принять» переносит черновик в степперы, в игру он попадает по «Начать раунд»;
  - итоги — `Round.tsx`: «Принять» записывает раунд, заблокирована при `sum_mismatch`.
- Вышедшие игроки в грамматику не попадают.
- Проверка: `npx vitest run` (черновики и адаптер), `node tools/explore/voice-e2e.mjs` (подмена `SpeechRecognition`, фразы из очереди).
