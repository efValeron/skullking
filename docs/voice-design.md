# Голосовой ввод: требования и дизайн

## Требования (со слов пользователя)
- Ввод имён игроков по очереди.
- Ставки в формате «имя количество». Если имя пропущено, у игрока 0.
- В конце раунда: кто сколько взял, бонусы и Кракен.
- Главное: отсеивать шум. За столом кто-то просто говорит имена, и это не должно считаться командой.

Допущение: команды диктует один человек (ведущий счёт), остальные разговаривают рядом.

## Принципы отсева шума (в порядке важности)
1. **Голос пишет только в поля открытого экрана, как ручной ввод.** С 2026-11-05 «Принять» нет (по просьбе Валерия и его игроков: смотреть вниз на черновик и жать «Принять» неудобно). Фраза сразу попадает в степперы, поля имён и «Кракен», изменённые поля подсвечены, «Вернуть» в шапке (или голосом «отмена») снимает последнюю фразу. В игру это попадает только по кнопкам экрана: «Новая игра», «Начать раунд», «Завершить раунд». «Завершить раунд» заблокирована, пока взятки не сходятся.
2. **Микрофон включается только кнопкой в шапке** и только в трёх окнах: имена, ставки, итоги раунда. Слушает без лимита, паузы его не выключают. Выключают стоп-слово в конце фразы («стоп», «готово», «всё», «хватит»), второй тап и уход с экрана: болтовня во время раунда не пишется. Слово-активатор не использовать: «кракен», «русалка», «пират» игроки выкрикивают сами. Цена отказа от подтверждения: чужая фраза вроде «Аня два», сказанная при включённом микрофоне, сразу попадёт в поле. Защита — подсветка и «Вернуть».
3. **Грамматика.** Имена — строго: одно лишнее слово, и вся фраза отклоняется. Ставки и итоги — нестрого (с 2026-11-05, по просьбе Валерия: «шум» — это прежде всего нечёткая диктовка, а не чужая болтовня):
   - слова-связки пропускаются: «так», «ну», «да», «есть», «всё», «взял», «у него»… (`COMMON_FILL`, `FILL_BIDS`, `FILL_RES` в `parser.ts`);
   - незнакомое слово не ломает фразу: оно пропускается, попадает в предупреждение «Не понял и пропустил: …» и сбрасывает текущего игрока. Поэтому число относится к имени, только если между ними одни связки, и «Дима, у тебя два туза» по-прежнему ничего не даёт;
   - поправка «нет», «вернее», «точнее», «ой» меняет уже названное число («Валера один, нет, два»);
   - повторное упоминание игрока заменяет сказанное о нём раньше: «Аня один … Аня два» даёт 2, «Валера плюс двадцать … Валера плюс двадцать» даёт 20, а не 40 (альянсы считаются отдельно, парой);
   - фраза отклоняется, только если из неё ничего не извлечено, или при явной ошибке: число больше карт, два разных числа подряд без поправки («Аня один два»);
   - из вариантов распознавания берётся первый, понятый целиком, иначе первый понятый с пропусками.
4. **Имя без числа не команда.** Ноль только явный («Аня ноль»). Неупомянутые игроки сохраняют то, что уже стоит в поле.
5. **Проверки по смыслу.** Ставка от 0 до числа карт. Сумма взяток равна числу карт (на 1 меньше, если был Кракен), иначе «Завершить раунд» заблокирована, а пока микрофон слушает, в шапке видно «Сумма взяток 1, нужно 2». Бонус засчитывается только при сошедшейся ставке (как и в оригинале), в шапке предупреждение.
6. **Несколько вариантов распознавания.** Движок отдаёт список вариантов (в Web Speech API это `maxAlternatives`), берётся первый, который проходит грамматику. Это заметно повышает точность имён.

## Окна и фразы
**Имена** (первое пустое поле подсвечено). С 2026-11-05 в одной фразе можно сказать несколько имён: «Аня, Дима и Оля Иван».
- Имена заполняют пустые поля по порядку, на лишние добавляются строки.
- Одно слово — одно имя, дефис допустим. Разделители — пробелы, запятые и «и». «Готово» в конце завершает ввод.
- Каждое слово проверяет `parseName` из voice-core: не число, не служебное слово, не дубль (ни с уже введёнными, ни внутри фразы). Плюс локальный список частых слов за столом, которые именем не бывают: «ходи», «уже», «твой», «подожди»… (`NOT_NAMES` в `src/voice/drafts.ts`).
- Одно непонятное слово отклоняет всю фразу. «Вернуть как было» откатывает её целиком.
- Если имя похоже на уже введённое (Аня / Ваня), показывается предупреждение и предложение дать прозвище.

**Ставки:** «Аня два, Дима один, Оля три», «ставки: у Ани два», «так, Валера два, Денис ноль, всё». Остальные получают 0.

**Итоги раунда:**
- взятки: «Аня два, Дима один, Оля ноль», «Валера взял один»;
- Кракен: «кракен», «кракен был», «без кракена»;
- бонусы — события и числа, складываются:
  - «бонус сорок», «плюс двадцать», «+20»: после «бонус», «плюс» или события любое число, кратное 10, — бонус; «Валера два двадцать» — тоже (взятки уже названы);
  - 14-я карта: «бонус четырнадцать» или «бонус 14» (+10), «чёрная четырнадцать» (+20);
  - «пират побил русалку», коротко «пират русалку» (+20 за каждую);
  - «чёрный пират побил пирата», коротко «пират пирата» (+30 за каждого: «пират двух пиратов» +60);
  - «русалка побила чёрного пирата», «русалка короля», «русалка пирата» (+40);
  - «лут» или «альянс» (+20): «лут и тридцать» = +50.
- альянс: «Валера один, альянс с Денисом» даёт +20 и Валере, и Денису; «с Денисом» не переключает игрока. Пара считается один раз, сколько её ни называй («Денис альянсом», «Денис альянс с Валерой» не добавят ещё 20). Партнёр может стоять и до слова: «Валера с Денисом альянс». Альянс без партнёра («Аня лут») — +20 только сказавшему. Засчитывать ли альянс (оба ли взяли ставки), решает диктующий: если не сошлось, просто не говорит «альянс». Свою ставку бонус всё равно проверяет: при промахе он обнулится;
- пример каши, которая разбирается: «Так Валера взял один бонусе есть да бонусы есть альянс с кем с Денисом Денис альянсом Денис ноль Миша ноль всё» → Валера 1 +20, Денис 0 +20, Миша 0;
- итоги можно диктовать частями, с паузами.

## Сессия диктовки (с 2026-11-05)
- Всё, что сказано с последней ручной правки, — один текст. Каждая новая фраза разбирается вместе с ним поверх формы, какой она была до первой фразы. Поэтому пауза не сбрасывает контекст («Валера…» — подумал — «…один» работает), а позднее упоминание побеждает.
- Пока человек говорит, промежуточный текст распознавания тоже разбирается: цифры появляются по ходу речи, а если браузер на ходу перерасслышал слово, поле поправится само.
- Фраза, из которой ничего не извлечено («Валера», «ну давай»), остаётся контекстом для следующей. Фраза с явной ошибкой (число больше карт, дубль имени, «Аня два» в окне имён) отбрасывается целиком, в шапке — «Не понял: «…» — причина».
- «Вернуть» (или «отмена») снимает последнюю фразу и пересчитывает форму. Ручная правка начинает сессию заново с поправленной формы и гасит подсветку.
- Код: `useVoice(state, setState, apply)` в `src/voice/Voice.tsx`; `apply*` в `src/voice/drafts.ts` переводят разбор voice-core в новую форму и список подсвеченных полей.

## Отображение
Шапка экрана: слева меню или «назад», справа «Вернуть» (после голосовой правки) и микрофон. Пока микрофон слушает, вместо заголовка идёт услышанный текст: длинный обрезается слева, видны последние слова. Под ним заметка: «Не понял: …» (красным), «Не понял и пропустил: …» или проверки раунда. После остановки остаётся только ошибка. Поля, которые заполнил голос, подсвечены мёдом.

## Движок речи
- Web (PWA): Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`), `lang = 'ru-RU'`, `interimResults = true`, `maxAlternatives = 5`, `continuous = false`: браузер останавливается после каждой паузы, движок сразу запускает его снова, пока не вызван `stop()` (в continuous-режиме Chrome на Android повторяет уже сказанный текст). Тишина (`no-speech`) и `aborted` просто перезапускают; `not-allowed`, `audio-capture`, `network` выключают микрофон с сообщением. Если браузер трижды подряд сразу завершает сессию, ничего не услышав, движок сдаётся. На некоторых Android каждый перезапуск может пикать — проверять на телефоне. Лучше всего в Chrome на Android; в Safari/iOS (особенно в установленной PWA) бывают проблемы с микрофоном, в Firefox API нет. Обычно нужен интернет. Грамматики (`SpeechGrammarList`) в Chrome фактически игнорируются, поэтому отсев делается после распознавания.
- Нужны офлайн или жёсткий отсев на уровне движка: Vosk (малая русская модель около 50 МБ) с ограниченным словарём (имена игроков, числа, служебные слова; всё остальное превращается в `[unk]` и отклоняется).
- Движок должен быть за интерфейсом (`start()`, `stop()`, `onResult(alternatives: string[])`), чтобы заменять его без правки логики.

## Ядро `voice-core/`
Чистый TypeScript без зависимостей (`parser.ts`), 102 теста (`npm install && npm test`), общий набор случаев в `cases.json` (его можно прогнать и на другом языке).
- `parseName(alts, players, { maxWords? })`
- `parseBids(alts, players, { cards })` → черновик `{ bids }`; `mergeBids`, `completeBids` (нули для неупомянутых)
- `parseResults(alts, players, { cards })` → черновик `{ tricks, bonus, kraken? }`; `mergeResults`
- `validateResults({ players, cards, draft, kraken?, bids? })` → `Issue[]` (`sum_mismatch` — сумма не сходится, `bonus_ignored` предупреждает)
- Результат парсера: `{ ok: true, draft, warnings, heard }` или `{ ok: false, reason, detail?, heard }`.

Допущения ядра (менять в `parser.ts`): «четырнадцать» считается бонусом только после слова «бонус»; события вроде «русалка побила чёрного пирата» работают без слова «бонус»; числа для бонуса кратны 10.

## Проверка шумом
Прогон 17 фраз с болтовнёй за столом («Дима, у тебя два туза», «Андрей, кракен выйдет, зуб даю», «Аня, ходи уже» и т. п.): 14 отклонены, пропущены только 3 фразы, которые буквально выглядят как команда («Аня два», «Оля один», «Иван, один»). Их отличить нельзя никакой грамматикой: от них защищают подсветка, «Вернуть» и выключенный между окнами микрофон (до 2026-11-05 — черновик с подтверждением). При доработке грамматики добавляй новые шумовые фразы в `cases.json`.

После перехода на нестрогий разбор (2026-11-05) прогон 18 фраз болтовни: пропускаются те же 3 «буквальные команды» и «Дима взял две взятки подряд» в итогах (Дима 2, «подряд» в «не понял»). Один «кракен» среди непонятных слов («Андрей, кракен выйдет, зуб даю», «Иван, кракен у тебя был?») отклоняется; «кракен был» принимается.

## Решения (этап 4, 2026-11-05)
Валерий не ответил на открытые вопросы, взяты рекомендации; поменять можно, логика от них не зависит:
1. Кнопка «Говорить»: тап, одна фраза, браузер сам останавливает после паузы. Повторный тап во время записи — стоп. С 2026-11-05 заменено: микрофон в шапке, слушает до стоп-слова, без «Принять» (см. принципы 1–2).
2. Голосового ответа нет.
3. Без офлайна: Web Speech API. Vosk можно подключить за тем же интерфейсом `SpeechEngine`.
4. Целевое устройство — Android Chrome. На iPhone (Safari, особенно установленная PWA) Web Speech API ненадёжен; если играете на iPhone, вопрос движка нужно открыть заново.
5. Голос доступен при любом языке интерфейса, распознавание всегда `ru-RU` (грамматика voice-core русская). Сначала он был только в ru-локали, но на телефоне с английским языком кнопка пропадала (2026-11-05). Скрыт только в браузерах без Speech API (Firefox и т. п.).

## Реализация
- `src/voice/engine.ts` — интерфейс `SpeechEngine` и адаптер Web Speech API с перезапуском после пауз.
- `src/voice/drafts.ts` — `applyNames` / `applyBids` / `applyResults` (разбор voice-core → новая форма и подсвеченные поля), `roundIssues`, тексты отказов, команды «отмена» и стоп-слова; тесты рядом.
- `src/voice/Voice.tsx` — хук `useVoice` (сессия диктовки), `voiceLive` (текст в шапке), `VoiceButtons` («Вернуть» и микрофон).
- Окна:
  - имена — `Players.tsx`: имена попадают в пустые поля по порядку (первое пустое обведено), в игру — по «Новая игра»;
  - ставки — `Bids.tsx`: сразу в степперы, в игру — по «Начать раунд»;
  - итоги — `Round.tsx`: сразу в открытый раунд (как степперы), раунд закрывает «Завершить раунд».
- Вышедшие игроки в грамматику не попадают.
- Проверка: `npx vitest run` (связка и адаптер), `node tools/explore/voice-e2e.mjs` (подмена `SpeechRecognition`: фразы и промежуточный текст из очереди, `'END'` — браузер сам остановился).
