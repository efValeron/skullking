# Спецификация оригинала (реконструкция из `main.dart.js`)

Источник: ветка `pwa` репозитория `skullkingkraken/skullkingkrakenapp`, минифицированный `main.dart.js` (dart2js). Исходников нет, поэтому это реконструкция.

Метки достоверности:
- **[код]** прочитано прямо в коде или в таблицах строк;
- **[вывод]** логический вывод из кода;
- **[проверить]** нужно проверить вживую в приложении.

## 1. Общее
- Flutter web (PWA), только портретная ориентация, Material-виджеты, версия 1.0.0+1 [код].
- Языки: en и ru, выбор по локали [код].
- Данные хранятся локально в браузере (localStorage), сервера нет [код].
- Шрифт: файл Pangolin-Regular.ttf под именем семейства «Pirate» [код]. Pangolin есть в Google Fonts.

- В теме встречаются цвета #C2525B, #EEE3CB, #F6ECD9; роли не установлены, сэмплировать со скриншотов [код].
- Манифест PWA: name «Skull King Kraken», orientation `portrait-primary` [код].

## 2. Экраны и порядок [код]
`startPage → playersPage → gameOptionsPage → bidsPage → roundPage → leaderboardPage → (следующий раунд) → bidsPage …`

Режимы экранов: Players (создание / редактирование), GameOptions (создание / редактирование) [вывод], Bids (`beforeRound` / `edit`), Leaderboard (`show` / `finishRound` / `edit`) [код].

### Старт [проверить расположение]
Пункты по строкам: «Новая игра», «Продолжить», «Предыдущие игры». Диалоги подтверждения: «Начать новую игру?» и «Начать раунд заново?».

### Игроки [код]
- Для каждого игрока поле «Введите имя» с автодополнением по ранее введённым именам (фильтр по вхождению подстроки без учёта регистра).
- Создание: кнопка «−» удаляет игрока.
- Редактирование: вместо «−» переключатель «в игре». Выключен значит «Игрок вышел» (флаг `away` в последнем раунде). Статус переносится на следующие раунды.
- Кнопки добавления игрока и «Сохранить»: [проверить].

### Параметры игры [код]
- «Раунды»: степпер `totalRounds`, по умолчанию 10. При изменении лимит карт сбрасывается (`maxCards = null`). Уменьшать нельзя ниже `startRound`, а в режиме редактирования ещё и ниже номера последнего раунда.
- «Начать с раунда»: степпер `startRound` (только при создании), от 1 до `totalRounds`.
- Блок про число карт: сообщения «Для таких параметров игры требуется N карт, но в наборе всего M карт» и «Ограничить количество карт в последних раундах до N, тогда потребуется M карт» [код: строки; логику расчёта и размер колоды проверить].
- Создание: кнопка «Начать игру» создаёт первый раунд, сохраняет игру и открывает ставки. Редактирование: кнопка «Сохранить».

### Ставки раунда [код]
- Заголовок: «Ставки для раунда N» (`beforeRound`) или «Изм. ставки для раунда N» (`edit`).
- Строка игрока: имя и степпер ставки от 0 до `cardsInRound`. У вышедшего игрока степпер отключён.
- До 5 игроков одна колонка, больше 5 сетка из 2 колонок.
- Сводка: «В игре X ставок из Y» (X — сумма ставок, Y — число карт).
- Кнопка: «Начать раунд» (`beforeRound`) или «Сохранить» (`edit`).

### Раунд [код]
- Заголовок «Раунд N».
- Строка игрока: имя, ставка, степпер взяток (0..`cardsInRound`), бонус (степпер с шагом 10, не ниже 0) и кнопка выбора пресета бонуса (нижний лист с 6 пунктами, см. раздел 5).
- Переключатель «Кракен» на раунд.
- Кнопка «Завершить раунд» активна, только если сумма взяток равна `cardsInRound`. Как учитывается Кракен — [проверить].
- Строка «В N раунде взято X ставок из Y» [код: строка; где показывается — проверить].

### Таблица очков [код]
- Режимы: `show` (просмотр во время игры), `finishRound` (после «Завершить раунд»; дальше «Следующий раунд»), `edit` («Редактировать очки за раунды»).
- Первая колонка «№» (номер раунда), дальше по столбцу на игрока.
- Текст ячейки: «Ставок:X, Взято:Y», плюс «, Бонусы:Z» если бонус больше 0, плюс «, Очков за раунд:S» если раунд завершён. У вышедшего игрока: «Игрок вышел».
- Если число карт в раунде отличается от номера раунда (лимит карт), рядом с номером показывается число карт; подсказка (en: «Round:N, Cards:M») [вывод].
- В режиме редактирования тап по ячейке открывает нижний лист правки (ставка, взятки, бонус); кнопки «Применить», «Сбросить», «Сбросить изменения» [вывод; логику проверить]. Подсказка «Нажмите на пункт в таблице чтобы изменить очки за раунд».
- Итого по игроку: сумма очков по раундам (расположение проверить).
- Игра завершена, когда `startRound + (rounds.length − 1) ≥ totalRounds` и все раунды завершены. Тексты «Игра завершена», «Результаты».

## 3. Модель данных (ключи JSON) [код]
```
Game       { playerNames: string[], rounds: Round[], totalRounds: number (=10),
             startRound: number (=1), maxCards: number|null, startDate: ISO string }
Round      { number, players: PlayerRound[], kraken: bool, bidsFixed: bool,
             finished: bool, cardsInRound: number }
PlayerRound{ bid, trick, bonus, away: bool }
```
- Текущий раунд — последний элемент `rounds`.
- Новый раунд: `number = startRound + rounds.length`; `cardsInRound = number`; если `maxCards != null` и `number > maxCards`, то `cardsInRound = maxCards`. Флаг `away` копируется из предыдущего раунда.
- Хранение: в стиле shared_preferences для web (ключи с префиксом `flutter.`, значения JSON-строкой) [вывод]. Точные ключи посмотреть в DevTools [проверить]. Есть список прошлых игр («Предыдущие игры») и «Продолжить».

## 4. Подсчёт очков [код]
```
вышел (away)                       → 0
ставка == взятки:
    ставка == 0                    → cardsInRound*10 + bonus
    иначе                          → ставка*20 + bonus
ставка != взятки:
    ставка == 0                    → −(cardsInRound*10)
    иначе                          → −|ставка − взятки| * 10
```
Если ставка != взятки, бонус обнуляется (бонусы засчитываются только при точной ставке). Очки игрока = сумма по раундам.

## 7. Что проверить вживую (чек-лист для этапа 1)
1. Расположение и вид кнопок на старте; как выглядят «Продолжить» и «Предыдущие игры»; что показывает список прошлых игр.
2. Экран игроков: кнопка добавления, минимум и максимум игроков, пустые имена, дубли имён, подсказки имён.
3. Параметры игры: размер колоды и расчёт «нужно карт», как работает ограничение карт, значения по умолчанию.
4. Ставки: сетка для 6+ игроков, поведение степпера на границах, сводка «В игре X ставок из Y».
5. Раунд: где «Игрок вышел», как открывается список бонусов, как ведёт себя «Кракен» и условие активации «Завершить раунд».
6. Таблица: итоговые очки, подсветка лидера, правка ячеек и кнопки «Применить» / «Сбросить», экран «Результаты» после последнего раунда.
7. Анимации и переходы между экранами, поведение кнопки «Назад», тактильные отклики.
8. Ключи и формат данных в localStorage (DevTools → Application).
9. Сыграть 3–4 раунда и сверить очки с формулой из раздела 4.
